# Zeku for Homebrew

[Zeku](https://zeku.dev) is a calm place to write for your Astro site: a native app that opens your project, knows your frontmatter schema, and publishes through your own git.

```bash
brew install --cask davidvkimball/zeku/zeku
```

This installs the same universal app you can download from [zeku.dev](https://zeku.dev/download), for macOS 10.15 and later, and Zeku keeps updating itself. Zeku is free for 14 days, then a one-time license from [zeku.dev/pricing](https://zeku.dev/pricing).

Remove it with `brew uninstall --cask zeku`.
